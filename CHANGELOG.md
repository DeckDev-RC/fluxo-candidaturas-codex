# Changelog

As mudanças relevantes deste monorepo seguem
[Keep a Changelog](https://keepachangelog.com/pt-BR/1.1.0/) e versionamento
semântico quando aplicável.

## Não lançado

### Adicionado

- estrutura npm workspaces com desktop e pacote PowerShell;
- licença Apache-2.0, DCO e arquivos de governança;
- CI, revisão de dependências, scanner de segredos e release com proveniência;
- documentação e screenshots sintéticos para portfólio;
- aprovação autenticada para ações externas do navegador;
- consentimento versionado para transmissão ao SkynetChat.

### Alterado

- fixtures e documentação pública sanitizadas;
- trava local endurecida para execução concorrente em CI.

## Histórico do aplicativo

O histórico detalhado das versões até `v1.4.1` permanece em
`apps/desktop/CHANGELOG.md`. A release `v1.4.1` continua disponível como artefato
legado anterior à preparação open source.
