# Security policy

## Supported versions

Security fixes are considered for the latest published version on `main`.

## Reporting a vulnerability

Do not open a public issue with exploit details, credentials, personal data or customer information. Use GitHub's private vulnerability reporting/security advisory flow when it is enabled for this repository. Include a concise description, affected version, reproduction steps and potential impact.

Please allow time for validation before public disclosure. Never include real tokens, sessions, database exports or private screenshots in a report.
