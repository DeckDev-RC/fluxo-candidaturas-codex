# Suporte

## Onde pedir ajuda

- Dúvida de uso ou desenvolvimento: GitHub Discussions.
- Bug reproduzível: issue usando o formulário de bug.
- Proposta de funcionalidade: issue de melhoria ou discussão prévia.
- Vulnerabilidade ou possível vazamento: siga `SECURITY.md`; não publique detalhes.

Antes de abrir uma issue:

1. procure por relatos existentes;
2. teste na versão mais recente;
3. execute `npm test` quando o problema for de desenvolvimento;
4. remova dados pessoais, URLs privadas, tokens, cookies e conteúdo de currículo.

## Escopo do suporte

O projeto mantém o código do Fluxo e suas integrações. Não oferece suporte às
contas, cobranças, disponibilidade ou políticas de OpenAI, SkynetChat e
plataformas de emprego. CAPTCHA, MFA e bloqueios do provedor não são contornados.

O projeto é fornecido sem garantia, conforme a licença Apache-2.0. Prazos de
resposta dependem da disponibilidade dos mantenedores.
