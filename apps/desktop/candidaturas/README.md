# Controle de candidaturas

- `candidaturas.json`: fonte estruturada privada, com histórico, resultado e evidência.
- `controle-candidaturas.md`: tabela detalhada gerada pelos scripts.
- `painel.md`: metas por plataforma e pendências.

Use `nova-candidatura.ps1`, `registrar-evento.ps1` e `registrar-resultado-teste.ps1`. Não edite os relatórios manualmente quando puder regenerá-los com `gerar-painel.ps1`.
