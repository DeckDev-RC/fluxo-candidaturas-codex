# Currículo

Coloque aqui o currículo principal em `.pdf` ou `.docx`.

Recomendação de nome:

```text
curriculo-nome-sobrenome.pdf
```

Se houver versões por objetivo, use nomes claros, por exemplo:

```text
curriculo-backend-python.pdf
curriculo-fullstack-node-react.pdf
```

Registre no `perfil/candidato.md` qual versão é a padrão. Currículos reais são ignorados pelo Git neste pacote.

Execute `scripts/extrair-curriculo.ps1` para criar uma versão `.txt` privada que possa ser consultada e comparada sem alterar o original.
